Manage the content visitors see on your portfolio. Sign in with GitHub to update your projects, skills, site files, and uploaded media.

What you can manage

Projects

Add, edit, remove, reorder, and link project cards shown on the Projects page.

Skills

Update skill names and progress levels shown on the Skills page.

Images and files

Upload images or documents to the repository, then select them in project records or page code.

Site pages

Edit the HTML and CSS for the rest of your portfolio in the source editor.

  1. Sign in to Pages CMS with the GitHub account that owns the portfolio.
  2. Install the Pages CMS GitHub App for mickeyway-ai/portfolio when prompted.
  3. Choose this repository and its publishing branch. Open Portfolio projects or Portfolio skills for the structured editors, or upload files to images/uploads.
  4. Save your changes. Pages CMS commits them to GitHub. If GitHub Pages deployment is enabled, it publishes the update.

Keep your site safe: only install the GitHub App on your own account and give repository access only to people you trust. The editor works with HTML and CSS source code.
